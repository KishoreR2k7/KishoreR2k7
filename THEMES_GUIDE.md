## 🔄 How to Switch Themes

To set any theme as your active GitHub profile:
1. Open the theme file you prefer (e.g. [`README_BENTO_GRID.md`](file:///c:/kishore/KishoreR2k7/README_BENTO_GRID.md) or [`README_CYBER_TERMINAL.md`](file:///c:/kishore/KishoreR2k7/README_CYBER_TERMINAL.md)).
2. Copy its content.
3. Paste and replace into [`README.md`](file:///c:/kishore/KishoreR2k7/README.md).
4. Commit and push to your `KishoreR2k7/KishoreR2k7` repository on GitHub:
   ```bash
   git add README.md
   git commit -m "Switch to new profile theme"
   git push origin main
   ```
